# 阿卡姆档案：1926 调查员资料集

《克苏鲁的呼唤》7 版资源包。一个可以直接开自由团的阿卡姆，也可以当作任何 1920 年代模组的舞台。

> 1926 年秋，马萨诸塞州阿卡姆。纺织厂一半停工，河的水位比往年低了两英尺，露出河床上一段不该存在的石砌台阶。这个月镇上失踪了三个人，警局的结论都是「醉酒失足」。

- **类型**：沙盒资源包（无固定剧本）
- **时长**：可支撑 3–4 次团
- **内容**：世界书 28 条（12 条公开 / 16 条守秘人专属），地图地点 11 个
- **时代**：1926 年，禁酒令时期

## 十一个地点

**学院区**：密斯卡托尼克大学、奥恩图书馆、研究生宿舍

**城区**：中央码头、格雷夫斯古董店、铜钥匙酒馆、警局、《阿卡姆广告人报》报社

**城郊**：女巫屋、河床石阶、阿奇博尔德宅

每个地点都写明了可调查物与线索走向，不是只有一句描述。

## 这个世界在讲什么

这座城有一件所有人都知道、但没有人说的事：**每隔一些年，河会「收」几个人。** 不多，三五个。够让报纸写三天，够让警局结三次案，不够让任何人追问下去。

三份失踪卷宗的措辞几乎一样，连「失足」两个字的写法都一样——同一个打字员，同一台机器。

老家族们照常开舞会，照常对报纸保持沉默，照常在礼拜天出现在同一排长椅上。

## 怎么用

### 当自由团沙盒

不装任何冒险包，选这个世界直接开局。世界模板自带开场：四个陌生人因为落款同为 `H.R.` 的信，在中央码头躲雨时相遇。之后完全自由——查失踪、查河床、查大学、查老家族，四条线都能走。

### 当别人的模组舞台

阿卡姆是 CoC 最通用的 1920 年代舞台。如果你的模组需要一个有大学、有图书馆、有警局、有黑帮码头、有老钱家族的美国东海岸城镇，直接用这个。

## 守秘人要点

1. **三层真相分开给。** 表层是「三个人失踪」；中层是「河床上有台阶，台阶通向水里」；深层是「这条河每隔一些年收几个人，而城里有人知道，并且配合」。前两层让玩家自己查，第三层留到最后。
2. **老家族不要演成反派。** 他们不是坏人，他们只是「知道但不说」——因为这比说出来的代价小。这种沉默比阴谋更难对付。
3. **大学是双刃剑。** 密斯卡托尼克大学既是最大的信息源（图书馆、教授、标本），也是最危险的——因为那里的人会「研究」而不是「躲开」。
